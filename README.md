# OpenSourceHub

**OpenSourceHub** — это веб-платформа для управления программными проектами и репозиториями кода.  
Система предоставляет удобный интерфейс для хранения, редактирования и распространения программных решений через браузер.

---

## Возможности

| Функция | Описание |
|---------|----------|
| 📁 **Управление репозиториями** | Создание и хранение проектов со структурированной системой файлов. |
| ✏️ **Редактирование файлов** | Просмотр и изменение кода напрямую через веб-интерфейс. |
| 📤 **Загрузка файлов** | Быстрая загрузка файлов и управление содержимым проектов. |
| 📥 **Скачивание проектов** | Экспорт репозиториев и доступ к исходному коду. |
| 🔐 **Безопасность** | Надёжное хеширование паролей, контроль доступа, защита от SQL‑инъекций и XSS. |
| 🗂️ **Работа с файлами** | Встроенный менеджер файлов с возможностью создания, переименования и удаления. |
| 👤 **Аутентификация** | Регистрация, вход (включая Google OAuth) и восстановление пароля. |

---

## Технологический стек

- **Backend:** PHP 7.4+ · MySQL
- **Frontend:** HTML5 · CSS3 · JavaScript (Vanilla)
- **Библиотеки:** PHPMailer (отправка писем), Vanta.js (фоновая анимация)
- **Аутентификация:** Google OAuth 2.0
- **Безопасность:** bcrypt для паролей, подготовленные запросы, CSRF‑защита
